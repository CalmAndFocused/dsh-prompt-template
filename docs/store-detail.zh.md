# 提示词优化器

不用离开输入框，直接改好你正在写的提示词。

## 它做什么

输入框工具行右侧有一个 **提示词优化** 胶囊（`Alt+O` 同效）。写下想改进的提示词，点开选一个模式，改写结果**逐字流式**出现：推理过程先到，正文随后，随时可取消。满意就点「填入输入框」，结果落回编辑器。

三种模式对应三种真实需求：把它重构成结构化角色提示词、把含糊请求说清楚、或在现有提示词上做一处针对性改动。

## 它解决的具体问题

普通的「润色」会把你的指令当闲聊处理。比如写「帮我优化：不要交互」，常见的模型会回你「好的，我不会与您交互」——它执行了你的需求，而不是把需求写进提示词。

这个插件把原文本当作**证据**（嵌在 JSON 里）交给模型，并要求模型改写这段文本本身。所以「不要交互」会被融进提示词，变成「请直接给出完整方案，不要与用户多轮确认」。

同时它守住三件事：

- **变量占位符逐字保留**。`{{location}}` 这类运行时变量不会被改名或填成具体值，面板会列出检测到的变量。
- **只输出提示词**。没有前言、解释或代码块围栏；Host 端还会再剥一次模型自作主张的前缀。
- **默认不改你的草稿**。结果只出现在面板里，点确认才写回。

## 模型与配置

默认使用你当前的会话默认模型，零配置。也可以填一个 OpenAI 兼容端点作为优先路由，key 存在宿主的凭据库中而非配置文件里。

**设置 → 通用 → 提示词优化** 可改默认模式、端点、温度、最大输出 token、超时。

## 也给 agent 用

同一个操作暴露为 `optimize_prompt` 工具，助手在你要求改进提示词时会直接调用它，而不是在回复里另写一遍。

## 要求

DeepSeek Harness 0.2.1-rc.2 及以上，无运行时依赖。
